# Search strings

## What to do
1. Read the search string of each database; edit the synonyms if a block is missing.
2. Press **Count the query** or **Count and check seeds** to see how many records and seed papers the query finds
   on OpenAlex (with online lookups on; your own databases are not searched, so their counts differ).
3. When the strings are final, freeze them: on Concepts and synonyms, press **Freeze** on the approved synonyms
   version. Then run the searches in each database yourself and press **Continue to Search results**.

## Why it matters
- Databases differ in syntax and limits; one shared query keeps the strings consistent and reproducible, and the
  freeze keeps the query from being tuned to the validation seed papers.

## What you need
- Approved concepts and synonyms.

## Done when
- The search is frozen.

## Watch out
- Unlocking is recorded in History. If validation papers were shown, you choose whether they count as seen or stay as validation; that choice is final and every output states it.
- If you already retrieved records elsewhere, this step is optional: record the outside search here if you can.
