# Overview

## Page role
- where the project stands, what needs you and the step to take next; it opens first when you open the project

## What to do
1. Start with **Continue**: it names the recommended step, and offers the page where you stopped if that differs.
2. Then deal with anything under **Needs attention**, in any order.

## Why it matters
- WIDER works out each step's state from the project every time, so this page always matches what is in the folder.

## What you need
- Nothing; this page only reads the project.

## Done when
- Nothing to finish: it changes as you work. Every step stays open from the sidebar.
